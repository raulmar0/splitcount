# Entre Implementation Plan

> **For agentic workers:** Implement scoped tasks in parallel with one final independent review. Steps use checkbox syntax for tracking.

**Goal:** Publicar una app funcional de gastos compartidos en GitHub Pages.

**Architecture:** React estático, cálculos monetarios puros y persistencia local validada. Interfaz adaptable sin rutas de servidor.

**Tech Stack:** React, Vite, lucide-react, Node test runner.

**Spec:** docs/superpowers/specs/2026-10-27-entre-design.md

## Global Constraints

- Todo el texto de producto en español.
- Importes enteros en centavos y sin conversión de monedas.
- Repositorio público y publicación GitHub Pages autorizados por el usuario.
- Guardado local explícito, sin simular sincronización ni transferencias bancarias.

## Review Focus

- Centavos restantes al repartir entre tres personas: conservar el importe total.
- Repartos exactos inválidos: impedir guardado.
- Pago registrado: reducir deuda sin alterar gastos.
- Importación inválida: conservar datos existentes.
- Móvil y teclado: acceso a navegación y formularios completos.
